# Коллоквиум — два курса

Единая платформа на базе приложения дискретной математики. Включает дискретную математику (1 модуль) и математический анализ (2 модуль). Старый сайт матанализа и его репозиторий не изменяются.

## Возможности

- Общий экран продолжения подготовки, выбор курса, адресуемые страницы через hash-маршруты.
- Дискретная математика: все 46 вопросов, 145 заданий, 12 этапов / 84 пункта плана, прежние фильтры и два генератора билетов.
- Матанализ: все 87 материалов, 43 официальных устных формулировки, 290 уточнений, интервальные повторения, устный экзаменатор и симуляция с прежними таймерами и баллами.
- Закладки на конкретные материалы обоих курсов. Хранятся локально, включены в общий экспорт.
- Журнал затруднений по самооценкам завершённых билетов. Исторические оценки не меняются вслед за текущим статусом.
- Общая резервная копия, импорт обоих прежних форматов, предварительный подсчёт конфликтов и выбор между текущими и импортируемыми записями. Истории объединяются по ID. Перед записью сохраняется локальная копия исходных данных.
- Один аккаунт Supabase для обоих курсов; локальный режим работает без настройки облака.

## Разработка

Node.js 24, npm:

```sh
npm ci --cache /tmp/colloquium-npm-cache
npm run dev
npm run test:unit
npm test
npm run test:materials
node scripts/verify-platform.mjs
npm run build
```

Сборка и проверка для GitHub Pages:

```sh
VITE_BASE_PATH=/colloquium-discrete-1module-hseami/ npm run build
npm run test:pages
```

Workflow проверяет оба курса и публикует общий сайт по адресу репозитория дискретной математики. Настройки Supabase передаются через прежние публичные GitHub Variables; приватные ключи не нужны. После изменения Variables нужна новая сборка.

## Структура

- `src/main.tsx`, `src/platform/` — общая оболочка, реестр курсов, ссылки, закладки, журнал и резервные копии.
- `src/DiscreteApp.tsx`, `src/data/`, `src/Practice.tsx`, `src/PreparationPlan.tsx` — сохранённый курс дискретной математики.
- `src/calculus/` — перенесённый курс матанализа с исходной моделью и тестами.
- `src/Sync.tsx`, `src/sync-engine.ts` — общий аккаунт и движок синхронизации с отдельными адаптерами курсов.
- `public/materials/`, `public/sources/` — оригиналы обоих курсов; `docs/platform-source-manifest.json` фиксирует SHA-256 всех 163 файлов.

Стили каждого курса подключаются только при его открытии. Курсы используют общий стек React 19 / TypeScript 6 / Vite 8, но сохраняют независимые правила оценки и генерации билетов. Данные дискретной математики остаются JSON, матанализа — типизированными TS-модулями. Полной переписи или конвертации учебного корпуса нет.

## Прогресс и совместимость

Прежние ключи не переименовываются и не очищаются:

- `discrete-study-v1`, `discrete-practice-v1`, `discrete-plan-v1`, `discrete-sync-v1`;
- `predel-v1`, `predel-v1-questions`, `predel-run` (последний — sessionStorage);
- добавлены `colloquium-platform-v1` для закладок и `predel-sync-v1` для очереди матанализа.

GitHub Pages одного владельца имеет общий origin. В том же браузере платформа видит старые локальные данные обоих курсов. Другому браузеру или домену нужен импорт или настроенная синхронизация. Не очищайте хранилище для обновления приложения.

Теория, самостоятельное доказательство, уточнения, планы и расписания не приравниваются друг к другу. Старые баллы, состав билетов, ID, даты и черновики матанализа сохраняются. У дискретного курса черновики и незавершённые билеты, как и прежде, не переживают перезагрузку. Незавершённая симуляция матанализа остаётся в той же сессии вкладки; в общий экспорт она не входит.

Общий импорт не удаляет отсутствующие в файле записи. Существующие значения сохраняются по умолчанию; можно явно выбрать значения файла для конфликтующих записей. Неизвестный формат или ошибочные оценки отклоняются до изменения данных. Техническая копия перед последним импортом хранится в `colloquium-before-import-v1`; она не содержит токенов аккаунта.

Старый сайт матанализа не использует новый протокол облака. Для занятий с синхронизацией открывайте курс в общей платформе; прежний сайт остаётся доступным как самостоятельная версия.

## Подключение облака

Если Supabase ещё не подключён, оба курса работают локально. Если подключён только прежний дискретный курс, его таблица, очереди, ревизии и RPC продолжают работать без изменений.

Для добавления синхронизации матанализа выполните в том же проекте дополнительную миграцию:

`supabase/migrations/202610290001_calculus_progress.sql`

Она создаёт отдельную таблицу `calculus_progress` с RLS и RPC `sync_calculus_progress`; существующие строки дискретной математики не изменяет. Переключение аккаунтов сохраняет локальную копию каждого курса отдельно. При отсутствии миграции приложение показывает ошибку подготовки облака и сохраняет локальный прогресс.

Общая инструкция входа и настройки проекта: [docs/sync-setup.md](docs/sync-setup.md). Реальный Supabase этой среды не настроен: проверены PostgreSQL/PGlite и два браузерных контекста с тестовым API, а не доставка писем настоящего проекта.

## Оформление

Общий экран и оба курса оформлены в единой светлой палитре с фиолетовыми, мятными и персиковыми акцентами. Учебные иллюстрации — локальные SVG-компоненты `src/platform/LearningArt.tsx`; шрифт Onest поставляется локально через Fontsource и не обращается к Google Fonts. Лицензия шрифта — SIL Open Font License.

`src/platform/platform.css` отвечает за общую оболочку, `course-theme.css` — за внешний вид сохранённых курсов, включая тёмную тему матанализа. Декоративное движение ограничено несколькими циклами; `prefers-reduced-motion` отключает анимации и переходы. Карточки показывают только фактический прогресс из прежних сохранений. Тесты оформления проверяют ширины 320–1280 пикселей, загрузку шрифта с того же адреса и отключение движения.

## Поиск, тренировка по ошибкам и обсуждение материалов

- `#/search` — общий поиск по 278 материалам и 290 уточнениям. Индекс включает формулировки, ответы, доказательства, подсказки, примеры и дополнительные варианты доказательств. Фильтры курса и типа, подсветка совпадений, выдача по 12 результатов. Запрос и фильтры остаются в ссылке. Открывается из шапки, с главного экрана и по Ctrl/Cmd+K. Переход к уточнению показывает и фокусирует именно нужный вопрос, сохраняя скрытие ответа.
- `#/recovery` — тренировка по низким самооценкам исходных билетов. Состав: до 3, 5 или 10 уникальных материалов, один или оба курса. Сначала собственный ответ, затем подсказка и разбор; явная самооценка разрешена после открытия разбора. Она обновляет текущую карточку и, для матанализа, расписание повторения. Исходные баллы и истории билетов не изменяются. Пропуск не выставляет оценку.
- Результаты тренировок находятся в необязательном `sessions` внутри прежнего `colloquium-platform-v1`. История тренировок хранится локально и входит в общий экспорт; статусы карточек используют существующий протокол синхронизации курса. Старые копии без `sessions` совместимы и не стирают новые тренировки при импорте. Сеанс можно продолжить после перезагрузки той же вкладки; черновик ответа после перезагрузки не сохраняется. Новое затруднение в более позднем билете возвращает материал в подборку, даже если прежнее уже разобрано.
- «Поделиться карточкой» формирует точную ссылку, включая ID уточнения, и поддерживает ручное копирование при запрете Clipboard API.
- «Сообщить о неточности» подставляет курс, ID, ссылку и редактируемый фрагмент учебного ответа. Пользователь описывает проблему, после чего может открыть предзаполненный черновик GitHub Issue или скопировать текст. Обращение не отправляется автоматически; пользовательские черновики ответов, оценки и данные аккаунта не подставляются.

Новые экраны оформлены в общей палитре: отдельные метки курсов, подсветка поиска, шкала сеанса, отметки разобранных затруднений и доступные модальные окна с возвратом фокуса. Содержимое первоисточников и схемы прежних курсов сохранены.
